#Calculadora Modular em C

Uma calculadora de console desenvolvida em **Linguagem C** para treinar modularização de código com funções, estruturas de decisão e laços de repetição.

## O que tem no código?

- **Funções separadas:** Operações matemáticas isoladas (soma, sub, mult, div) recebendo parâmetros e retornando valores.
- **Menu interativo:** Roda em um loop do-while controlado por opções numéricas.
